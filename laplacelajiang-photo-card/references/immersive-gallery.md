# 廿四境桌面展馆合同（v4）

## 固定输出

- `previews/style-gallery.html`：Three.js 桌面三维主展馆；
- `previews/打开廿四境展厅.cmd`：启动 localhost 状态桥并打开展馆；
- `previews/style-gallery-accessible.html`：二维展品清单技术回退；
- `previews/style-gallery.png`：分享、打印与最低能力回退；
- `previews/exhibition/`：本地 Three.js、GSAP、PBR 材质和优化展品；
- `previews/gallery-manifest.json`：目录、能力、主题和运行时声明。

统一运行：

```powershell
python scripts/photo_card.py gallery <delivery>
python scripts/photo_card.py serve <delivery> --open
```

## 桌面范围

- 只验收桌面浏览器；推荐 1920×1080，最低 1366×768，覆盖 2560×1440 和超宽屏。
- 小于最低视口时显示桌面提示，不提供移动布局、移动摇杆或触屏自由行走。
- 主展馆必须通过 localhost 打开，以便真实读写选择锁和包装状态；`file://` 仅给出明确启动指引。

## 空间与观看

1. 使用真实 Three.js 透视场景、PBR 材质、灯光、阴影和深度；建筑为正对主墙的中央展湾与向后收束的侧廊，不使用廉价弧形挡板或整片纯色色块。
2. 入口是深色木质前厅：母片、黄铜门把、双扇门和一次自动靠近。入场后相机停在能同时看清展品与墙签的固定策展位。
3. 入场后墙面、地板、侧廊和相机保持稳定。右侧“下一幅”是主切换控件，左侧“上一幅”和方向键是补充。切换以约 850ms 光幕、作品显影、墙签更新和局部照明完成，不移动整座展厅。
4. 主界面不得出现自由行走、指针锁定、WASD、移动摇杆或“无障碍参观”按钮。点击作品或按 E 进入细看。
5. 标题在墙签、名册、细看层和技术回退中必须单行完整显示；空间不足时按实测宽度缩小字号，不能换行、省略或遮挡。

## 展品、名册与镜语室

- 每幅展品都有唯一编号、独立策展标题、与母片事实一致的两三句简介和可读的小号风格注记。预设内部名称不能放大充当标题。
- 细看层以可辨认但虚化的展厅为背景；左侧为编号、标题、简介、风格、来源和收藏操作，右侧完整 `contain` 展示横图、竖图或方图，禁止裁切。
- 主墙与细看画框支持有限左右拖动。偏移、Y 轴旋转、离墙深度、墙面空隙和阴影同步变化，松手阻尼回正，并区分点击与拖拽。
- 细看层支持按住比较母片，以及细节镜缩放、滚轮和拖动查看。
- “展品名册”先展示亚麻硬壳封面，再在胡桃木阅读台上打开双页；每跨页 4 幅，共 6 章。前后翻页要有可见纸页翻动，卡片可直达展品。
- “镜语室”提供 24 式索引、当前风格摘要、基础配方和进阶控制，可复制当前配方。

## 收藏与真实进度

- 收藏袋允许首次选择 1–6 幅，可加入、移出和复核；归档后可追加新批次，不能覆盖旧选择。
- 确认收藏后，浏览器通过 localhost JSON API 写入 `selection.lock.json` 与 `packing-status.json`，展示 `take-home/` 绝对取件路径。
- 页面只读取真实状态文件。等待、渲染、合成、质检、打包和完成均由实际文件状态驱动，禁止用定时器伪造高清生成进度。
- 完成后每幅至少包含 `final/master.png`、`final/xhs-3x4.jpg`、`展签.md`、`generation-record.json` 和 `qa-record.json`，并生成取件网页、取件单、manifest 与 ZIP。

## 默认材质与光影

- 暮光私人收藏馆：暖象牙灰泥、浅色白橡木地板、深色红桃花心木画框、旧黄铜细边、亚麻名册和胡桃木阅读台。
- 地面和木作必须使用真实 PBR 颜色、法线和粗糙度贴图，呈现板缝、木纹、结疤、色差和柔和漆面反光。
- 主光模拟 2700K 轨道展灯，环境加入克制的冷色暮光；作品优先，阴影柔和棕灰，不用纯黑吞没空间。
- 导视、弹窗和取件处统一使用奶油白、陶土、胡桃木与低饱和黄铜。温馨不等于堆装饰，不添加与母片无关的人物、植物或虚构展品。

## 性能与回退

- 自动检测 GPU 能力并提供“流畅／均衡／精细”手动档；限制像素比、阴影分辨率和浮尘数量。
- 尊重 `prefers-reduced-motion`；关闭开门、切换、翻页和摆动时，浏览与收藏功能仍可用。
- 页面隐藏时暂停渲染循环；关闭弹窗后停止状态轮询；资源加载失败时显示二维回退入口。
- 不加载 CDN、远程字体、分析脚本或外部图片；Three.js、GSAP、纹理和展品全部随包本地提供。

## 原创与许可边界

Kage 只启发“入场—聚焦—挑选—取件”的叙事。不得复制其内容、图片、文字、字体、品牌、场景或代码。本展馆使用独立 Three.js 建筑与交互；外部 PBR 材质只使用已记录许可的资源，并保留第三方声明。

## 验收

- 1366×768、1920×1080、2560×1440/超宽屏均无文字重叠、画面裁切和不可达控件；
- 入场、前后切换、细看、母片比较、细节镜、拖动画框、名册开合与翻页、镜语室、收藏复核和状态同步均可操作；
- 展品切换时建筑与相机不移动，光幕时长符合合同；
- 名册每跨页 4 幅、共 6 跨页，标题单行完整；
- 展品完整显示，暖色材质、光影、阴影和纵深通过实机截图检查；
- 主页面无远程依赖，二维回退和静态 PNG 可独立打开；
- `doctor`、`self-test`、`validate_delivery.py` 和三轮人工巡展均通过。
