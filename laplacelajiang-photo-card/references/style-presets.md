# Style preset registry

本文件是面向人的预设说明。`integrated-preset-catalog.json` 是机器执行时的唯一目录；每个二级标题必须与 JSON 中的预设 ID 一一对应并进入缩略图画廊。视频类项目在这里仅提炼“静帧视觉语言”，不扩展为视频制作流程。

## `fashion-sketch`

- 缩略图标签：Fashion Sketch / 时装手稿
- 视觉骨架：暖白艺术纸、大留白、黑色墨线和石墨、寻找式轮廓、单一提取强调色。
- 适用：人物、产品、行李、建筑轮廓和有明显姿态或方向的照片。
- 精细生成：保留主体结构，让背景和衣褶保留松动笔触；避免粗糙涂鸦、卡通和整图模糊滤镜。

## `retro-travel-collage`

- 缩略图标签：Retro Travel Collage / 复古旅行拼贴
- 视觉骨架：奶油纸、低饱和复古色、照片切片、撕纸边缘、几何纸片和编辑标题区。
- 适用：旅行、城市、建筑、街拍、风景和多图输入。
- 精细生成：优先使用输入照片作为拼贴证据；避免随机地标、虚构旗帜和难以读取的大字。

## `sparse-visual-abstraction`

- 缩略图标签：Sparse Abstraction / 稀疏视觉抽象
- 视觉骨架：原图与极简抽象面板并置；用少量形状、线条、色块和方向关系重述照片，而不是套滤镜。
- 适用：森林、街道、建筑、展览、旅行景观和具有明显前中后景的照片。
- 精细生成：只抽取照片中可验证的色彩、数量、轮廓、遮挡、负空间和运动方向；保留不对称和空间层次，禁止凭空增加物体。

## `editorial-memory-panel`

- 缩略图标签：Editorial Memory / 编辑记忆面板
- 视觉骨架：照片主画面、柔和的记忆色板、局部几何符号、克制英文短标题和小型注释形成杂志式双页。
- 适用：有个人叙事、旅行片段、日常观察或单一情绪的照片。
- 精细生成：抽象面板必须能回溯到原图的光线、色块、轮廓和情绪；照片保持真实，文字后期合成，避免伪造地点和故事细节。

## `structured-scene-narrative`

- 缩略图标签：Scene Narrative / 场景叙事卡
- 视觉骨架：模块化卡片、清晰网格、主图与局部放大、证据标签和阅读顺序；像一本小型视觉档案。
- 适用：人物动作、空间观察、物件说明、旅行记录和需要解释“看到了什么”的照片。
- 精细生成：先建立主体—环境—细节—情绪四层关系，再安排信息层级；标签只能描述照片实际可见内容，不能伪造数据或地点。

## `paper-collage-halftone`

- 缩略图标签：Paper Halftone / 纸张网点拼贴
- 视觉骨架：旧纸、丝网印刷网点、粗细不一的纸片、手工撕边、黑色图形和一枚高饱和强调色。
- 适用：户外人物、街拍、海报感建筑、运动姿态和主体轮廓清楚的照片。
- 精细生成：将照片切成有限层次的纸片和网点，不改变人物身份或主体动作；保留可辨认的主要轮廓，避免脏乱背景和过度噪点。

## `infographic-editorial`

- 缩略图标签：Infographic Editorial / 信息图编辑卡
- 视觉骨架：照片、简洁图标、比例线、箭头、坐标或分区标记组成高可读性版面；颜色数量少、层级明确。
- 适用：植物观察、空间结构、物品拆解、路线记录和需要说明关系的照片。
- 精细生成：只把实际观察转换成图形关系；没有可靠数值时使用定性标签，不虚构统计、地理位置或测量结果；所有精确文字交给后期排版。

## `poetic-white-paper`

- 缩略图标签：Poetic White Paper / 白纸诗性复原
- 视觉骨架：近白纸张、轻微铅笔或蜡笔线、少量柔和色块、细小诗句和安静的边缘留白。
- 适用：人物背影、旧物、自然细节、低清照片和需要温柔修复感的画面。
- 精细生成：以原照片轮廓和姿态为锚点做轻量修复与诗性转译；不把缺失细节补成确定事实，不使用强烈光晕、塑料质感或过度锐化。

## `eastern-silk-cinema`

- 缩略图标签：Eastern Silk Cinema / 东方绢本电影感
- 视觉骨架：绢本纤维、墨色远景、低饱和青绿或朱砂、留白、轻雾和纵向题签式信息区。
- 适用：山林、古建、人物背影、自然姿态和具有东方留白气质的照片。
- 精细生成：只借用材质、留白和层次气氛，不擅自添加神话人物、历史服饰、法器或具体朝代符号；主体动作和现实环境仍以原图为准。

## `handdrawn-diary-storyboard`

- 缩略图标签：Handdrawn Diary / 手绘日记分镜
- 视觉骨架：一至三格手绘小画面、纸张底、简短旁注、箭头和轻微手写感；画面像一页视觉日记。
- 适用：多图输入、连续动作、旅行过程、亲子记录和希望表达“发生顺序”的素材。
- 精细生成：每格对应一张真实输入图或一个可验证的动作阶段；没有多图时只做单格叙事，不凭空补齐前后情节。

下面的预设不是简单复制已有风格，而是把参考项目公开展示的“结果形态”单独注册出来。它们可以和前面的风格预设混选：前者决定成品像什么，后者决定材质、色彩和抽象语言。

## `photo-abstraction-study`

- 缩略图标签：Photo Abstraction Study / 照片抽象研究图
- 参考结果：[travel-photo-abstraction](https://github.com/Evianis/travel-photo-abstraction)
- 结果形态：原始照片、证据分析和一块稀疏抽象板组成的结构研究图；突出轮廓、重复、方向、负空间和层次。
- 适用：有明显空间结构、重复树干、建筑线条、路径或主体轮廓的照片。
- 精细生成：每个抽象标记都要对应照片事实；原照片保持未改写，不能使用外部示例图或移除参考项目水印。

## `photo-memory-editorial`

- 缩略图标签：Photo Memory Editorial / 照片记忆编辑页
- 参考结果：[photo-abstract-editorial](https://github.com/ZzzLc0405/photo-abstract-editorial)
- 结果形态：主要摄影区域、抽象记忆面板、一个原创短标题和少量编辑注释组成竖版编辑作品。
- 适用：旅行片段、日常观察、带有个人情绪但不需要虚构故事的照片。
- 精细生成：摄影区只使用用户原图；面板从色彩、形状、空间节奏派生；精确文字后期合成。

## `vision-director-board`

- 缩略图标签：Vision Director Board / 视觉导演方案板
- 参考结果：[editorial-vision-studio](https://github.com/Yu-0312/editorial-vision-studio)
- 结果形态：像导演提案板的单页输出，包含主视觉、镜头意图、材质试验、构图备选和统一的视觉关键词区。
- 适用：需要把一张照片发展成明确艺术方向，或需要比较多种构图决策的项目。
- 精细生成：方案板中的每个备选都必须围绕同一张照片和同一证据矩阵，不把占位示意当作事实，不伪造制作信息。

## `halftone-broll-frame`

- 缩略图标签：Halftone B-roll Frame / 半调拼贴画面
- 参考结果：[gbro-collage-broll](https://github.com/pyang5166/gbro-collage-broll)
- 结果形态：一帧具有运动感的纸张拼贴画面，使用半调网点、切纸层、粗边、胶带感色块和明确的视觉重心。
- 适用：人物姿态、户外动作、街拍、建筑或有强烈轮廓的照片。
- 精细生成：只生成静帧卡片，不生成 B-roll 视频；纸片和网点必须服务于源照片的动作与结构。

## `data-story-poster`

- 缩略图标签：Data Story Poster / 数据叙事海报
- 参考结果：[Infographic](https://github.com/antvis/Infographic)
- 结果形态：主图配合关系图、流程、分区、图标和层级化标签，把可见观察组织成一张信息叙事海报。
- 适用：植物、物件、空间、路线、步骤或可被分组比较的照片。
- 精细生成：无可靠数值时只表达定性关系；不得编造统计、测量、地理数据或项目结论。

## `prompt-styleboard`

- 缩略图标签：Prompt Styleboard / 提示词风格板
- 参考结果：[AI-Visual-Prompt-Cookbook](https://github.com/VigoZhao/AI-Visual-Prompt-Cookbook)
- 结果形态：同一照片的多个小型视觉样张、风格标签、材质色板和可复用参数区，像一页可筛选的风格目录。
- 适用：用户尚未确定方向，需要比较风格语言、色彩和材质组合的场景。
- 精细生成：把本次照片分析结果写入变量，再生成样张；不得复制外部项目的私有提示词、品牌资产或原始参考图。

## `scene-card-archive`

- 缩略图标签：Scene Card Archive / 场景卡档案
- 参考结果：[scene-card-studio](https://github.com/swping999/scene-card-studio)
- 结果形态：主照片、细节裁片、事实标签、叙事摘要和编辑网格组成可编辑的场景档案卡。
- 适用：人物与环境关系明显、需要说明“主体—空间—细节”的照片。
- 精细生成：信息模块只描述画面可见内容；细节裁片必须来自源图，不能用随机素材填充版面。

## `one-frame-metaphor`

- 缩略图标签：One Frame Metaphor / 一帧一隐喻
- 参考结果：[one-frame-one-metaphor](https://github.com/estherliu-lab/one-frame-one-metaphor)
- 结果形态：用一个清晰、克制的视觉转译把源照片中最有辨识度的事实组织成单帧隐喻海报，画面只有一个主隐喻和明确焦点。

## `minimal-zine-poster`

- 缩略图标签：Minimal Zine Poster / 极简 Zine 海报
- 参考结果：[gc-minimal-zine-poster](https://github.com/LiamGvchi/gc-minimal-zine-poster)
- 结果形态：竖版旧纸海报，保留 70%–90% 负空间，只放一个小型视觉锚点、一处高纯度强调色、克制的实验字体区域和轻微复印／孔版／网点缺陷。
- 适用：主题安静、主体明确、细节可被压缩为小型拼贴锚点，或希望获得诗性独立杂志气质的照片。
- 精细生成：照片作为编辑目标时先记录身份、服装、姿态和环境的保留级别；默认用兼容适配器，用户明确要求原生流程且本机路由可用时才调用 `gc-minimal-zine-poster-v0-3`。

## 自定义临时预设

对用户上传的参考图、文档或文字提炼以下六项，并在本次画廊中新增一个临时条目：

1. 构图：比例、主体位置、留白和阅读顺序；
2. 材质：纸张、印刷、胶片、墨线、颗粒和边缘；
3. 色彩：底色、主色、强调色数量和对比度；
4. 形式：照片、线条、色块、纸片、符号和抽象面板关系；
5. 字体：衬线／无衬线／等宽、字重、大小和对齐；
6. 禁止项：拥挤、无关元素、错误文字和风格冲突。

临时预设不写回本文件，除非用户明确要求将它固化为新的内置预设。
